Factory Protocol v0.5.1 — Tool Dependency Update

Open factory-protocol-v0.5.1-standalone.html in Chrome, Edge or Firefox.
No account, installation, network or server is required. All artwork is embedded.

Choose 0–4 resource cards. LIMITED LOADOUT warns but never blocks START MISSION.
Resource evidence requires an unlocked card in your deck, with a remaining use.
Select it, then ROLL D20 to use it and spend a charge. Selection alone reveals no evidence.
VISUAL INSPECTION ONLY: observations/inferences and explicitly sourced HMI/log readings.
TOOL REQUIRED: the resource is absent, locked or depleted; that resource action is unavailable.
MEASUREMENT AVAILABLE: the instrument/reference is usable, with evidence pending actual use.

Required resources:
Multimeter: voltage, current, continuity.
Pressure Gauge: pneumatic pressure.
Leak Detection Spray: small leak localization.
Precision Alignment: exact alignment.
Wiring Diagram: wiring route and terminal trace.
Sensor Datasheet: operating limits and specifications.
PLC Sequence Reference: sequence/interlock semantics.
Thermal Trend: temperature/load trend.

All six missions have playable empty-deck routes. Longer observations, isolated manual
inspections and additional downtime can replace faster resource-assisted diagnosis,
but never fabricate instrument evidence. Existing HMI, VFD and logs retain their values.
The no-tool S6 route adds visible retained connector service marks; the pneumatic route
finds visible tube damage after isolated removal. Site isolation services control access
where the player cannot perform the instrument-backed absence-of-voltage test.

Charges, D20, Second Check, support time costs, reputation, career XP, sequential mission
unlocking and non-undo backtracking remain in use. Newly unlocked cards are not auto-selected.
Save keys are fp-v051-*: stable v0.5 data is read only for migration; beta saves are untouched.
Older releases are immutable. Historical save keys are never overwritten.

Validation: 585 assertions; six mission graphs / 71 nodes / 17 checks / 7 manual nodes;
36 successful resource-use cases and 144 blocked or unselected cases; six actual zero-card
playthroughs; JavaScript syntax passed; no browser errors; embedded image payloads identical.
See VALIDATION.json and manifest.json for details and SHA-256 hashes.
