# Factory Protocol v0.4 — Campaign Foundation

This release is the approved baseline before Chapter One expansion.

## Playable campaign

1. Mission 001 — **No Signal** — photoelectric sensor troubleshooting.
2. Mission 002 — **Overcurrent** — motor/VFD symptom vs mechanical load.
3. Mission 003 — **False Trigger** — optical interference, operator interview and calibration.
4. Mission 004 — **Pressure Drop** — pneumatic leak, energy isolation and safe repair.

## Systems included

- Mission Schema v1 metadata.
- NPC communication nodes.
- Persistent reputation: Safety, Reliability, Teamwork.
- Career progression separated from mission/card unlocks.
- Deck selection and unlock progression.
- Fail-forward, review/backtracking, downtime and performance scoring.
- Standalone web build for frictionless classroom testing.

## Files

- `factory-protocol-v0.4-standalone.html` — self-contained playable build.
- `campaign-metadata-v0.4.json` — campaign metadata separated from presentation.
