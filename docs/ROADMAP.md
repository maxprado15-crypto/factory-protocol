# Factory Protocol — Roadmap

## Current baseline — v0.4
Campaign Foundation with four missions, Mission Schema v1, deck progression, persistent reputation, career progression, NPC integration, mission consequences, and standalone web build.

## v0.5 — Chapter One
Primary goals:
- Mission 005: Sequence Error
- Mission 006: Night Shift
- Chapter 1 campaign/map presentation
- strengthen deck-building choices before each mission
- broaden card effects and tradeoffs
- create additional Technician avatar evolution art
- polish NPC dialogue and English variation

## v0.6 — Teacher Playtest
Primary goals:
- stable six-mission classroom package
- run with real students
- observe completion time, wrong-choice patterns, card usage, language comprehension, replay interest, and frustration points
- rebalance difficulty, XP, downtime, Safety/Production penalties, and D20 thresholds
- evaluate whether students voluntarily want another mission

## After classroom validation
Only after the six-mission Automation chapter is stable:
- extract/solidify generic campaign engine
- choose the second vocational campaign (Administration, HR, Web/Internet Computing, or Electronics/Electrotechnics)
- build a second campaign to test cross-domain reuse

## Later technical milestones
- Phaser presentation client when useful for richer animations/assets
- PWA deployment
- optional backend for classroom IDs/progress sync
- teacher dashboard only after the student loop is validated
- possible Unreal Engine 3D client in the long term while retaining content schema/rules

## Football branch
Football RPG remains a separate future campaign/product using the same concepts:
- player cards
- attributes
- tactical choices
- contextual cards
- D20/check resolution
- consequences/progression

It should be original rather than a direct eFootball clone.
