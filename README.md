# Factory Protocol v0.5.1 — Tool Dependency Update

Six-mission Industrial Automation educational RPG, based on the approved v0.5 visual standalone.

Download the [standalone HTML](releases/v0.5.1/factory-protocol-v0.5.1-standalone.html) or [ZIP](releases/v0.5.1/Factory-Protocol-v0.5.1.zip), then open locally in a browser.

- Start with 0–4 resource cards; LIMITED LOADOUT never blocks an unlocked mission.
- Instrument/reference evidence requires the correct unlocked, carried resource, selection and a spent charge.
- Observe and infer without tools; existing HMI/VFD/log readings stay available. Seven manual investigation nodes keep all six missions completable with zero cards.
- Preserve charges, D20, support costs, reputation, career progression and non-undo backtracking. v0.5.1 saves are isolated from stable and beta versions.

See [release instructions](releases/v0.5.1/README.txt), [validation](releases/v0.5.1/VALIDATION.json), [continuity](docs/CONTINUITY.md), and [decisions](docs/DECISIONS-LOG.md).

The [exact approved v0.5 baseline](releases/v0.5/factory-protocol-v0.5-standalone.html) is archived intact. Earlier v0.4/v0.4.1 source and beta-playtest records are preserved. Tool contracts live in src/v0.5.1. Build and validation scripts are under tools/v0.5.1.
